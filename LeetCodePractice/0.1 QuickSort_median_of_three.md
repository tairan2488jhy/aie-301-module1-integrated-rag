Quick sort picks a pivot element, partitions the array so elements smaller than pivot go left and larger ones go right, then recursively sorts the left and right partitions. 

### 1. median_of_three（三位取中）

英文：Median-of-three picks the median value among `arr[low]`, `arr[mid]`, `arr[high]` as pivot, to avoid worst-case O(n²) when input is already sorted or reverse-sorted.
中文：三位取中，从最左、中间、最右三个元素里选中位数当pivot，规避数组已经有序/逆序时快排落到最坏O(n²)的情况。

```python
def median_of_three(low: int, high: int) -> int:
    mid = (low + high) // 2
    # 三步比较，保证 arr[low] ≤ arr[mid] ≤ arr[high]
    if arr[low] > arr[mid]:
        arr[low], arr[mid] = arr[mid], arr[low]
    if arr[mid] > arr[high]:
        arr[mid], arr[high] = arr[high], arr[mid]
    if arr[low] > arr[mid]:
        arr[low], arr[mid] = arr[mid], arr[low]
    # 此时 mid 位置是三者中位数，把它交换到 high 位置，给 Lomuto 用
    arr[mid], arr[high] = arr[high], arr[mid]
    return high
```
英文：After three comparisons, `arr[mid]` is the median. We swap this median value to index `high`, because our Lomuto partition always uses `arr[high]` as pivot.
中文：三次比较完成后，mid位置就是三者中位数；把它交换到high下标，因为我们这个Lomuto分区固定拿`arr[high]`当pivot。

英文：Return high, so partition function knows where the pivot sits.
中文：返回high，告诉分区函数pivot现在在high这个位置。

> 关键点：它**不是直接返回中位数的值**，是把中位数挪到high，返回下标，适配Lomuto的写法。

### 2. lomuto_partition（Lomuto 分区方案）
英文：Lomuto partition rearranges the subarray `[low, high]` around pivot value. All elements ≤ pivot go left, elements > pivot go right.
中文：Lomuto分区重排 `[low, high]` 子数组：所有 ≤ pivot 的元素挪到左边，大于pivot的到右边。

```python
def lomuto_partition(low: int, high: int) -> int:
    pivot_val = arr[high]  # pivot就是刚才三位取中挪过来的那个中位数
    i = low - 1  # i：小于等于pivot区域的右边界
    for j in range(low, high):
        if arr[j] <= pivot_val:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    # 循环结束，i是<=pivot区间最后一个位置，pivot放到i+1
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1
```
英文：`j` is the scan pointer, iterate every element except pivot. `i` marks the boundary of elements that are ≤ pivot.
中文：j是遍历指针，扫描除pivot以外的所有元素；i标记「≤pivot元素区域」的右边界。

英文：At the end, swap pivot into position `i+1`. This is the final sorted index of pivot. Return this index for recursive quicksort.
中文：循环结束后，把pivot交换到i+1，这个位置就是pivot在有序数组里的最终位置；返回这个下标，给快排递归切分左右区间。

### 3. 两者串联完整流程（面试口述重点）
英文：Before partition, we run median-of-three to select a good pivot and move it to `high`. Then Lomuto partition uses `arr[high]` as pivot and returns pivot’s final index. We recursively sort left `[low, p-1]` and right `[p+1, high]`.
中文：分区之前先跑三位取中，选出一个质量更好的pivot并挪到high；然后Lomuto分区拿arr[high]做基准，返回pivot的最终下标；递归排左边`[low,p-1]`、右边`[p+1,high]`。

### 4. 和 Hoare 分区简单对比（面试官常追问）
英文：Lomuto is simpler to write, but has more swap operations. Hoare partition is faster in practice, with fewer swaps.
中文：Lomuto好写，但是交换次数更多；Hoare分区工程上交换更少、速度更快。

英文：Median-of-three is a common optimization for industrial quicksort to avoid worst case on sorted input.
中文：三位取中是工业快排标配优化，专门对付有序数组这种最坏场景。

### 5. 容易踩坑的理解误区
❌ 误区：median_of_three 返回中位数的值
✅ 真相：它交换元素，把中位数放到high，返回下标，适配Lomuto固定取右端点作为pivot的结构。

❌ 误区：i是pivot位置
✅ 真相：i是≤pivot区域末尾，pivot最后放在 i+1。
