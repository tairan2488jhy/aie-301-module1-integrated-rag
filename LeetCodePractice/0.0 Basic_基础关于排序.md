# 基础排序
### Bubble Sort 冒泡排序
Bubble sort repeatedly scans the array, compares adjacent elements, and swaps them if they are in the wrong order. Larger elements "bubble" toward the end of the array in each pass.
冒泡排序重复遍历数组，比较相邻两个元素，如果顺序错误就交换；每一轮会把较大元素逐步“冒泡”到数组尾部。

### Selection Sort 选择排序
Selection sort divides the array into a sorted part and an unsorted part. In each iteration, it finds the minimum element from the unsorted section and swaps it with the first element of the unsorted section.
选择排序把数组分为已排序区和未排序区，每一轮在未排序区间找到最小值，和未排序区间第一个元素交换。

### Insertion Sort 插入排序
Insertion sort builds the sorted sequence one element at a time. It takes each unsorted element and inserts it into its correct position within the already sorted prefix.
插入排序逐步构造有序序列，逐个取出未排序元素，将它插入前面已经排好序部分里合适的位置。

### Merge Sort 归并排序
Merge sort is a divide-and-conquer algorithm. It recursively splits the array into two halves, sorts each half separately, then merges the two sorted subarrays into one sorted array.
归并排序是分治算法：递归把数组对半拆分，分别排序两个子数组，最后把两个有序子数组合并成一个有序数组。

### Quick Sort 快速排序
Quick sort picks a pivot element, partitions the array so elements smaller than pivot go left and larger ones go right, then recursively sorts the left and right partitions.
快速排序选定一个基准值（pivot），分区：小于基准的放左边、大于基准的放右边，再递归对左右两个分区排序。

### Heap Sort 堆排序
Heap sort uses a max-heap (or min-heap) data structure. It first builds a heap from the input array, then repeatedly extracts the heap root (maximum value) and places it at the end of sorted region.
堆排序基于大顶堆（或小顶堆）：先把数组构建成堆，反复取出堆顶最大值，放到有序区末尾，再调整堆。

### Counting Sort 计数排序
Counting sort is a non-comparison sort. It counts occurrences of every distinct value, then uses the count array to reconstruct the sorted output. Only works well for data with a limited value range.
计数排序是非比较排序，统计每个数值出现次数，依靠计数数组还原有序结果；适合数值范围不大的数据。

### Radix Sort 基数排序
Radix sort sorts numbers digit by digit, starting either from the least significant digit (LSD) or most significant digit (MSD). It uses a stable sub-sort like counting sort for each digit position.
基数排序按数位逐轮排序，从最低位或者最高位开始，每一轮用稳定排序（如计数排序）处理当前数位。

### Shell Sort 希尔排序
Shell sort is an optimized insertion sort. It sorts elements separated by a fixed gap first, then shrinks the gap step by step until gap = 1, at which point it becomes standard insertion sort.
希尔排序是插入排序的优化版本：先按固定间隔分组排序，不断缩小间隔，直到间隔为1，退化为普通插入排序。

# 欧美算法面试高频排序（英文定义 + 中文对照，面试口述版）
> 重点说明：远程AI Agent / Backend岗位，**不会让你默写全部**；优先考原理、复杂度、稳定性、trade‑off、什么时候选哪个。
> 最高频梯队：QuickSort、MergeSort、HeapSort
> 次高频：Insertion Sort、Bubble Sort（大多用来对比、问短板）
> 基数/计数排序：偶尔问到，一般是问「非比较排序的适用场景」
> Shell、Selection：非常少考

## Quick Sort
Quick sort selects a pivot, partitions the array so items smaller than pivot move left and larger ones move right, then recursively sorts left and right partitions.
快速排序选一个pivot基准，分区：小值放左边、大值放右边，递归排序左右分区。
- Time：Avg O(n log n), Worst O(n²)
- Space：O(log n) recursion stack（in-place版本）
- Stable：❌ 不稳定
- Interview point：why worst case？how to avoid worst case（random pivot / median-of-three）

## Merge Sort
Merge sort is divide-and-conquer. Split array into two halves recursively, sort each half, merge two sorted subarrays.
归并排序：分治，递归拆成两半，分别排序，合并两个有序子数组。
- Time：O(n log n) guaranteed
- Space：O(n) extra array
- Stable：✅ 稳定
- Interview point：when you prefer merge sort over quicksort? Linked list sort!

## Heap Sort
Heap sort builds a max heap, repeatedly pop the heap maximum to the end of array, then heapify to maintain heap property.
堆排序先建大顶堆，不断取出堆最大值放到数组末尾，再堆化维护堆性质。
- Time：O(n log n)
- Space：O(1) in-place
- Stable：❌ 不稳定
- Interview point：vs quicksort，why heap sort less popular in practice

## Insertion Sort
Insertion sort maintains a sorted prefix; take one unsorted element and insert it into correct position in sorted part.
插入排序维护前面有序前缀，逐个把未排序元素插入有序区正确位置。
- Time：Best O(n), Worst O(n²)
- Space：O(1)
- Stable：✅ 稳定
- Interview point：good for nearly sorted small data；used inside Timsort

## Bubble Sort（大多是对比题，很少让你写）
Bubble sort repeatedly compare adjacent pairs and swap inversions, large elements bubble to tail.
冒泡排序反复比较相邻元素，逆序则交换，大数逐步浮到尾部。
- Time：Best O(n), Worst O(n²)
- Stable：✅稳定
- Interview point：only used for teaching；bad for large dataset

## Counting Sort / Radix Sort（非比较排序，偶尔提问）
Counting sort counts frequency of each value and rebuild sorted array, works only for bounded integer range.
计数排序统计频次重建有序数组，仅适合数值范围有限的整数。
Radix sort sorts digit by digit, uses stable sub-sort like counting sort for each digit.
基数排序逐位排序，每一轮依赖稳定子排序（计数排序）。
- Time：O(n + k) / O(d*(n+k))，**not bounded by O(n log n) comparison lower bound**
- Interview point：can we beat n log n sort? Only non-comparison sort with constraints.

# ✅ 面试一句话对比（高频追问）
1. Why QuickSort is default in many languages (Python Timsort / Java Arrays.sort for primitive)？
Quicksort has better cache locality, low constant factor.
快速排序缓存友好、常数开销更小。
2. MergeSort stable, QuickSort not — why stability matters?
Stable sort keeps original relative order for equal keys, useful for multi-key sort.
稳定排序保留等值元素原始相对顺序，多关键字排序很重要。
3. Timsort（Python内置sort，**超级高频！欧美必问**）
Timsort is hybrid: merge sort + insertion sort. It detects already sorted runs and merge them.
Timsort 混合归并+插入排序，识别已有序片段再合并，是Python、Java对象排序底层。
